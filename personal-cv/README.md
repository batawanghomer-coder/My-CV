## Project Description

This repository contains a personal CV webpage created as part of an IT415
activity. It is a simple, clean, and responsive single-page website that
presents my profile, education, technical skills, projects, and contact
information as a BSIT student and aspiring software developer.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Responsive design (desktop, tablet, mobile)
- Personal profile / hero section
- About Me section
- Education section
- Technical skills presented as cards and badges
- Projects section with project cards
- Contact information (email and GitHub links)
- Smooth scrolling navigation
- Mobile navigation menu

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in any web browser.

No server, build tools, or additional dependencies are required.
